# v0.6 — второй Моно пошёл

Второй игрок теперь **управляется вторым геймпадом**: ходьба левым стиком, камера правым,
прыжок на A. Split screen и второй Моно — как в v0.3, Шестая по-прежнему остаётся
AI-спутницей.

## Что внутри

| Файл | Что это |
|---|---|
| `ue4ss-patched.zip` | Рабочий UE4SS для этой сборки игры: `dwmapi.dll` + папка `ue4ss\` с **уже пропатченным** `UE4SS.dll` и настроенным `UE4SS-settings.ini`. Распаковать в `<игра>\Helios\Binaries\Win64\`. Тот же загрузчик, что в v0.3. |
| `LN2Coop-0.6.zip` | Только мод (`Scripts\main.lua`, `coop.cfg`, `README.txt`, `patch_ue4ss.ps1`) — если UE4SS уже установлен. Распаковать в `ue4ss\Mods\LN2Coop\`. |

## Установка

```
1) распаковать ue4ss-patched.zip  ->  <игра>\Helios\Binaries\Win64\
2) распаковать LN2Coop-0.6.zip    ->  <игра>\Helios\Binaries\Win64\ue4ss\Mods\LN2Coop\
3) в ue4ss\Mods\mods.txt должна быть строка:  LN2Coop : 1
4) подключить ДВА геймпада, запустить игру, «Продолжить»
```

Или одной командой из репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File tools\install.ps1 -GameDir "G:\Little Nightmares 2"
```

## Что нового по сравнению с v0.3

- **Причина, почему p2 стоял**: `AddMovementInput` на второго Моно не даёт ускорения даже
  с `bForce=true` (`IsMoveInputIgnored()` при этом `false`); игра не выполняет свои действия
  для второго игрока. Пад 2 при этом читается.
- **Мост ввода**: мод сам читает второй пад и ведёт пешку через
  `CharacterMovement.Velocity` каждые 33 мс. Работают коллизии, склоны, гравитация и
  анимация ходьбы. Скорость компенсирует торможение между тиками.
- **Камера p2** вращается правым стиком через `SetControlRotation`.
- **Прыжок p2** — принудительный `MOVE_Falling` + вертикальная скорость, потому что
  `Character::Jump()` игра для p2 игнорирует.
- **Постановка p2** ровно в точку p1 без свипа, с обнулением скорости и переводом в
  `MOVE_Walking`: пешка больше не проваливается сквозь мир, нижняя половина не чёрная.
- Капсула p2 игнорирует канал Pawn, чтобы два Моно не блокировали друг друга в точке
  спавна (побочный эффект: p2 проходит сквозь Шестую и врагов).

## Проверено

- второй локальный игрок создаётся (`local players 1 -> 2`, `ControllerId = 1`,
  `PlayerInput = HeliosPlayerInput`);
- игрок 2 — `BP_PlayerPawn_C` (Моно), не Шестая; экран делится, у каждого своя камера;
- ходьба вперёд/назад/вбок со второго пада, поворот камеры, прыжок;
- **в установленной игре пользователя**: в логе реальные значения стика p2 (`test=false`),
  позиция и скорость пешки меняются (`speed` 129–168), скриншот
  `docs/img/v0.6-user-game-pad.png`;
- меню не разделяется, старт уровня `PLVL_Wilderness` работает.

## Ограничения

- Полное прохождение вдвоём не проверено: двери, лифты, рычаги, захваты, сюжетные сцены,
  враги и чекпоинты рассчитаны игрой на одного игрока. Мост пока умеет только ходьбу,
  камеру и прыжок.
- Капсула p2 игнорирует других персонажей (см. выше).
- Кооп включается/выключается через `coop.cfg` и перезапуск игры.
- Игра ставится на паузу, когда окно теряет фокус.
- Патч `UE4SS.dll` привязан к сборке игры (SHA-256 exe `468DEF5F…F05F2`); на другой сборке
  не накладывать.
