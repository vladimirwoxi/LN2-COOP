# v0.6.1 — инверсия, спринт, прыжок

Исправления по итогам игры вдвоём в установленной v0.6. Второй Моно теперь
ходит в правильную сторону, бежит на **X** и прыгает на **A**.

## Что нового по сравнению с v0.6

- **Инверсия движения исправлена.** Сырые оси левого стика на этой сборке
  противоположны игровым: обе оси переворачиваются (`invertMoveX/Y`). Проверено
  пользователем — вверх идёт вперёд, влево идёт влево.
- **Спринт — X.** Игра мапит `ActionSprint` на `Gamepad_FaceButton_Left`; при
  удержании X мост пишет скорость 360 вместо 210. Проверено: второй Моно ускоряется.
- **Прыжок — A.** `IsInputKeyDown(A)` для второго игрока возвращает false, поэтому
  кнопка читается через аналоговое состояние (`GetInputAnalogKeyState`). Прыжок
  работает, повторное нажатие в воздухе не складывается.
- Карта действий игры пишется в лог: `ActionJump=A`, `ActionSprint=X`,
  `ActionCall=Y`, `EquipItem*=B`, `ActionCancelGrab=RT`.
- Убрана тяжёлая диагностика API, которая могла уронить игру.

## Что пока НЕ работает

- **Подбор предметов.** `ActionCall` (Y) вызывается, но предмет не подбирается;
  возможно, подбор автоматический или на LT. Это первая задача следующей сессии.
- Захват, двери, лифты, рычаги, чекпоинты, враги — по-прежнему логика на одного игрока.
- Капсула p2 игнорирует других персонажей (p2 проходит сквозь Шестую и врагов).

## Установка

```
1) распаковать ue4ss-patched.zip  ->  <игра>\Helios\Binaries\Win64\
2) распаковать LN2Coop-0.6.1.zip  ->  <игра>\Helios\Binaries\Win64\ue4ss\Mods\LN2Coop\
3) в ue4ss\Mods\mods.txt должна быть строка:  LN2Coop : 1
4) подключить ДВА геймпада, запустить игру, «Продолжить»
```

Или из репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File tools\install.ps1 -GameDir "G:\Little Nightmares 2"
```

## Управление игроком 2

- левый стик — ходьба;
- **X** — спринт (удерживать);
- правый стик — камера;
- **A** — прыжок.

В момент появления p2 стоит точно в точке p1 (проверенная точка на полу) и
отделяется после первого движения.
