# v0.7 — второй Моно подбирает предметы

Второй игрок теперь берёт предметы на **RT** и кладёт их повторным нажатием. Подбор идёт
через игровой `PickupComponent` предмета — тот же путь, которым пользуется первый Моно.

## Что было не так

Подбор предметов не был подключён: `ActionCall` (Y) вызывался, но предмет не брался.
Игра выполняет свои действия только для первого игрока, поэтому одного нажатия кнопки
недостаточно.

## Что найдено

- У обуви, шишек, палок и оружия есть компонент `PickupComponent`. Подбор — вызов
  `PickupComponent:TryPickUp(Holder)` **на предмете**, где `Holder` — пешка.
- Радиус внутри функции не проверяется: в тесте p1 подобрал обувь с расстояния 1391 юнит.
  Мод сам берёт ближайший предмет в радиусе 3.5 м.
- **Первый `TryPickUp` для p2 возвращает `false`**: интерфейс подбора второго игрока в
  «stowed»-состоянии. После `PlayerPickupInterface:ForceStowOrDrop()` следующий вызов
  срабатывает — в моде это автоматический retry.
- **`PickupComponent:TryThrow()` и `TryPutdown()` у p2 мгновенно роняют игру.** Поэтому
  бросок отключён, а «положить» идёт через безопасный `ForceStowOrDrop()`.
- `GetCurrentCarryable()`/`GetCurrentlyHeldPickup()` на этой сборке возвращают мусорный
  UObject даже при пустых руках — состояние «в руках» мод хранит сам.

## Что сделано

- RT (`Gamepad_RightTriggerAxis`, игровой `AxisGrab`) — взять/положить.
- Поиск ближайшего `PickupComponent` по владельцу-актору, радиус 3.5 м, кулдаун 0.4 с.
- Состояние `BRIDGE.heldPickup`, строка `p2 state` теперь пишет `held=`.
- A с предметом кладёт его (бросок пока не реализован).
- `tools/test_bridge.ps1 -Mode pickup`: подбор, ходьба с предметом, положить.
- `bridge_test.txt`: поля 14 (`grab`) и 15 (`pickupRadius`); опрос файла по тикам.

## Проверено

В изолированной копии `G:\LN2\test-install` (окно 1280×720, сейв `G:\LN2\save-test`):

```
pickup: holding BP_Carryable_ShoeBig_C_2147481067 holder=BP_PlayerPawn_C_2147481252 isP2=true
p2 state: ... held=true test=true      (во время ходьбы с предметом)
putdown fallback ForceStowOrDrop: ok=true
p2 state: ... held=false test=true
```

Игра осталась жива после подбора, ходьбы с предметом и того, как предмет положили.

## Установка

```
1) распаковать ue4ss-patched.zip  ->  <игра>\Helios\Binaries\Win64\
2) распаковать LN2Coop-0.7.zip    ->  <игра>\Helios\Binaries\Win64\ue4ss\Mods\LN2Coop\
3) в ue4ss\Mods\mods.txt должна быть строка:  LN2Coop : 1
4) подключить ДВА геймпада, запустить игру, «Продолжить»
```

Или из репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File tools\install.ps1 -GameDir "G:\Little Nightmares 2"
```

## Управление игроком 2

- левый стик — ходьба (модель поворачивается в сторону движения);
- **X** — спринт (удерживать);
- правый стик — камера;
- **A** — прыжок (с предметом — положить);
- **RT** — взять предмет / положить взятый.

## Что пока НЕ работает

- Бросок предмета: `TryThrow`/`TryPutdown` у p2 роняют игру, ищем безопасный путь.
- Захват, двери, лифты, рычаги, кнопки, чекпоинты, враги — игровая логика по-прежнему
  рассчитана на одного игрока.
- Капсула p2 игнорирует других персонажей (p2 проходит сквозь Шестую и врагов).
