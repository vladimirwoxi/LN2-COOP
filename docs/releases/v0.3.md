# v0.3 — split screen работает

Первый рабочий релиз: кооп Little Nightmares II **на одном ПК**, разделённый экран, два геймпада. Игрок 2 — второй Моно, Шестая остаётся AI-спутницей.

## Что внутри

| Файл | Что это |
|---|---|
| `ue4ss-patched.zip` | Рабочий UE4SS для этой сборки игры: `dwmapi.dll` + папка `ue4ss\` с **уже пропатченным** `UE4SS.dll` и настроенным `UE4SS-settings.ini`. Распаковать в `<игра>\Helios\Binaries\Win64\`. |
| `LN2Coop-0.3.zip` | Только мод (`Scripts\main.lua`, `coop.cfg`, `README.txt`) — если UE4SS уже установлен. Распаковать в `ue4ss\Mods\LN2Coop\`. |

## Установка

```
1) распаковать ue4ss-patched.zip  ->  <игра>\Helios\Binaries\Win64\
2) распаковать LN2Coop-0.3.zip    ->  <игра>\Helios\Binaries\Win64\ue4ss\Mods\LN2Coop\
3) в ue4ss\Mods\mods.txt должна быть строка:  LN2Coop : 1
4) подключить ДВА геймпада, запустить игру, «Продолжить»
```

Или одной командой из репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File tools\install.ps1 -GameDir "G:\Little Nightmares 2"
```

Скрипт сам проверит хеши, наложит патч `ProcessEvent`, поправит `UE4SS-settings.ini`, разложит мод и включит его в `mods.txt`.

## Проверено

- второй локальный игрок создаётся (`local players 1 -> 2`, `ControllerId = 1`, `PlayerInput = HeliosPlayerInput`);
- игрок 2 — `BP_PlayerPawn_C` (Моно), не Шестая;
- экран делится, у каждого своя камера;
- второй Моно ставится рядом с первым;
- старт уровня `PLVL_Wilderness`, меню не разделяется;
- `Add_IntInt(2,3) = 5` (патч ProcessEvent работает).

## Требования

- **Little Nightmares II Enhanced Edition** (GOG), exe SHA-256 `468DEF5F335F1984855818CFF8BBE0F2B2CD6D36AA0C57ACDE32A1D92E3F05F2`. На другой сборке патч не накладывать.
- Два геймпада, подключённые до запуска игры.

## Ограничения

- Полное прохождение вдвоём не проверено: двери, лифты, сюжетные сцены, враги и чекпоинты рассчитаны игрой на одного игрока.
- Ввод со второго физического геймпада проверялся только по `ControllerId`/`PlayerInput`.
- Кооп включается/выключается через `coop.cfg` и перезапуск игры.
- Игра ставится на паузу, когда окно теряет фокус.
