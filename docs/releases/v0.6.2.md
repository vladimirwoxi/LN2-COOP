# v0.6.2 — второй Моно поворачивается и анимируется

Исправление по итогам жалобы «у второго игрока нет анимации движения». Пешка p2 больше
не едет боком: она поворачивается в сторону ходьбы, как первый Моно.

## Что было не так

У обеих пешек одинаковые настройки: `bUseControllerRotationYaw = false`,
`bOrientRotationToMovement = true` — движок поворачивает персонажа **по вектору ускорения**.
Мост в v0.6.1 писал только `CharacterMovement.Velocity`, а `Acceleration` у p2 оставалась
нулевой, поэтому поворот не выполнялся вообще: модель смотрела в сторону, зафиксированную
при постановке, и скользила боком.

Анимация это видит напрямую. В `ANIM_BP_Player_C` есть две переменные:

- `Speed` — модуль скорости;
- `ForwardSpeed` — проекция скорости на «вперёд» модели.

До исправления у p2 было `Speed = 153`, `ForwardSpeed = 76` (модель смотрела на 60° в
сторону от движения) — локомоция получала «половину скорости вперёд» и оставалась в
холодной позе. У p1 при той же ходьбе было `Speed = 173`, `ForwardSpeed = 173`.

## Что сделано

- Мост поворачивает p2 сам: `faceMovement`, до 540°/с, коротким путём, только когда стик
  отклонён.
- После исправления `ForwardSpeed` совпадает со `Speed` в каждой пробе лога
  (178.1 / 178.1, 168.5 / 168.5, 154.7 / 154.7), а `yaw` p2 равен направлению скорости
  (`vel = 163.1,-59.1` → `yaw = -20.0`; `vel = -145.4,52.9` → `yaw = 160.0`).
- `math.atan2` в этой сборке Lua отсутствует (Lua 5.4) — угол считается через
  `math.atan(dy, dx)`.
- Убрана бесполезная запись `AddMovementInput` каждый тик (p2 от неё не двигался, на
  анимацию она не влияет).
- Тяжёлая диагностика анимации отключена по умолчанию: перебор свойств аним-графа
  останавливал игру на 6–9 с. Раз в секунду пишется одна дешёвая строка в `anim_dump.txt`.

## Проверено

В изолированной копии `G:\LN2\test-install` (окно 1280×720, сейв `G:\LN2\save-test`),
лог `p2 state` + `anim_dump.txt`:

- p2 идёт 155–178 ед/с, `mode=1`, `paused=false`;
- `yaw` p2 следует за направлением движения, `ForwardSpeed == Speed`;
- в логе нет `bridge error`.

Визуальную проверку анимации делает пользователь на своих падах: персонаж на экране
слишком мелкий, чтобы отличить шаг от скольжения по скриншоту.

## Установка

```
1) распаковать ue4ss-patched.zip  ->  <игра>\Helios\Binaries\Win64\
2) распаковать LN2Coop-0.6.2.zip  ->  <игра>\Helios\Binaries\Win64\ue4ss\Mods\LN2Coop\
3) в ue4ss\Mods\mods.txt должна быть строка:  LN2Coop : 1
4) подключить ДВА геймпада, запустить игру, «Продолжить»
```

Или из репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File tools\install.ps1 -GameDir "G:\Little Nightmares 2"
```

## Управление игроком 2

- левый стик — ходьба (модель поворачивается в сторону движения);
- **X** — спринт (удерживать);
- правый стик — камера;
- **A** — прыжок.

## Что пока НЕ работает

- Подбор предметов, захват, двери, лифты, рычаги, чекпоинты, враги — игровая логика
  по-прежнему рассчитана на одного игрока.
- Капсула p2 игнорирует других персонажей (p2 проходит сквозь Шестую и врагов).
